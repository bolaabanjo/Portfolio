I built `Wisc`, an AI chat application leveraging Next.js for the frontend, Vercel AI SDK for smooth integration, and Google Generative AI for real-time, streaming AI responses. The project features an intuitive UI where user messages and AI responses are clearly distinguished. As the third project in the '50 Projects, 50 Weeks' challenge, the focus was on quickly integrating powerful AI capabilities into a user-friendly interface.
[Check Repo](https://github.com/bolaabanjo/wisc)

---


Wisc is an AI chat application that enables real-time conversations with a Google Generative AI model, featuring streaming responses and a clean, intuitive user interface.

---

*   The rapid advancement of generative AI models presents an opportunity to create engaging conversational experiences.
*   Building a chat application that demonstrates real-time streaming capabilities and intuitive UI design is crucial for showcasing modern web development skills.
*   From a learning perspective, this project solidifies understanding of Next.js, Vercel AI SDK, and integration with powerful AI APIs.

---


*   **Goals:**
    *   Develop a functional AI chat application with a Google Generative AI model.
    *   Implement real-time streaming of AI responses.
    *   Create a clean and intuitive user interface for conversations.
    *   Ship a functional product as part of the '50 Projects, 50 Weeks' challenge.
*   **Constraints:**
    *   Rapid development cycle (one week, as part of the challenge).
    *   Focus on core chat functionality and AI integration.
    *   Leverage existing frameworks and SDKs for efficiency (Next.js, Vercel AI SDK).

---


*   **Frontend: Next.js** — Chosen for its robust framework capabilities, efficient routing, and server-side rendering benefits.
*   **AI Integration: Vercel AI SDK** — Utilized for its seamless integration with AI models and built-in support for streaming responses, simplifying the development of the chat interface.
*   **AI Model: Google Generative AI** — Selected for its advanced conversational capabilities, providing the intelligence behind the chat.
*   **Styling:** Implicitly, a modern CSS framework or custom styling for the UI elements.
*   **Font Optimization: `next/font` with Geist** — For automatically optimizing and loading fonts, enhancing performance and visual appeal.

---


```
[User Browser - Next.js UI] 
    ↕ User Message
[Next.js API Route (Vercel AI SDK)] 
    ↕ Request to AI Model
[Google Generative AI API] 
    ↕ Streaming Response
[Next.js API Route (Vercel AI SDK)] 
    ↕ Streamed AI Response
[User Browser - Next.js UI]

Nothing Fancy.
```
