## About

Gitstack is an open-source system that extends the philosophy of Git far beyond code. Traditional version control captures commits and branches, but misses the rest of what makes a project *work*, environments, dependencies, datasets, and system states. Gitstack versions it all.

It’s built for developers, researchers, and teams who want **reproducibility, reliability, and speed** without the “it worked on my machine” nightmare. Whether you’re building web apps, training ML models, or managing complex pipelines, Gitstack gives you total state control.

## Quick Start

Install Gitstack globally from [PyPI](https://pypi.org/project/gitstack):

<CodeBlock compact marginBottom="16" codes={[{
  code: "pip install gitstack",
  language: "bash"
}]} />

Verify the installation:

<CodeBlock compact marginBottom="16" codes={[{
  code: "gitstack time\n# Output: 08:48:15.743508\n\ngitstack date\n# Output: 2025-10-01",
  language: "bash"
}]} />

Initialize a new Gitstack project:

<CodeBlock compact marginBottom="16" codes={[{
  code: "cd my_project\ngitstack snap",
  language: "bash"
}]} />

This creates a `.gitstack/` directory that stores snapshot metadata and environment details.

## Basic Commands

Snapshot your project state:

<CodeBlock compact marginBottom="16" codes={[{
  code: "gitstack snap",
  language: "bash"
}]} />

Restore your last working state instantly:

<CodeBlock compact marginBottom="16" codes={[{
  code: "gitstack restore",
  language: "bash"
}]} />

Future workflows will support advanced commands like:

<CodeBlock compact marginBottom="16" codes={[{
  code: "gitstack deploy",
  language: "bash"
}]} />

…to deploy snapshots directly to containers or cloud sandboxes.

## Next Steps

Gitstack is evolving rapidly. Upcoming features include time-travel debugging (`gitstack rewind 2h`), AI-generated snapshot summaries, environment-aware deployments, and a visual dashboard for exploring your project’s evolution over time.

To contribute or explore the codebase, visit [Gitstack on GitHub](https://github.com/bolaabanjo/gitstack).  
We can push version control beyond code and into software itself.
