## Why Linear Algebra

Every ML model is matrix multiplication. Every physics simulation is a system of linear equations. Every 3D render is a series of transformations.

If you don't know linear algebra, you're borrowing tools you don't understand.

## Vectors

A vector is a quantity with magnitude and direction. But more importantly — it's an element of a vector space. The abstraction matters more than the geometry.

**Key operations:**
- Addition: v + w
- Scalar multiplication: c * v
- Dot product: v . w = |v||w|cos(theta)

## Matrix Transformations

A matrix is a linear transformation. That's it. Rotation, scaling, shearing, projection — all matrices.

## Eigenvalues

If Av = lambda * v, then v is an eigenvector and lambda is its eigenvalue.

Eigenvectors are the directions that don't change under a transformation. They're the *essence* of what a matrix does.
